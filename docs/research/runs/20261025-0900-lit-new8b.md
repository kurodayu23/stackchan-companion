**已知缺口（诚实声明）**：

- 只覆盖 arXiv + Semantic Scholar 两个源；ACM DL / IEEE / 期刊付费墙内的论文可能缺。
- 检索式是**相关性排序的前 N 条**，不是穷举；`max_results` 可调。
- Semantic Scholar 的引用数会随时间变化 ⇒ **重跑本文件内容会变**。已生成的文件视为快照，日期以文件头「取证时间」为准。
- arXiv API 要求请求间隔 ≥ 3 秒，全量抓取需要数分钟。
