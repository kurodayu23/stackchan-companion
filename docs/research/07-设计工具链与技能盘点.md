## 2. matrix 连接器：本机的「多模态设计流水线」（12 个工具，实测可用）

调用方式：`mcode-tools connector call connector__matrix__<tool> --args '<json>'` 或 `--args-file <path>`

### 2.1 找参考（调研阶段主力）
| 工具 | 参数 | 实测情况 |
|---|---|---|
| `connector__matrix__search_images` | `{"queries":[{"task_name":"t1","query":"<搜索词>","prompt":"<相关性过滤>"}]}` | ✅ 实测一次返回 5 组共 50 张图 + 原图 URL + 来源站点 + 原文链接 |
| `connector__matrix__reverse_image_search` | 仅传 `image_url` | 可用（未深度验证） |

### 2.2 看图理解（把图变成可执行结论）
| 工具 | 关键坑 |
|---|---|
| `connector__matrix__describe_images` | ✅ 实测成功分析 8 张图。**坑：只接受 HTTPS URL，直接塞外网 URL 会失败**（报 `image_info.url could not be used as a media source`）。正确流程：`Invoke-WebRequest` 下载 → `mcode-tools upload_temp_url <local>` 拿 temp_url → 再传 temp_url。可传 per-image prompt 做定向提问 |

### 2.3 生成素材（面向用户的部分要用户过目）
| 工具 | 用途 | 注意 |
|---|---|---|
| `connector__matrix__generate_image` | 文生图 / 图生图（`input_urls`）。**表情帧、背景插画、App 图标、壁纸** | 参数要包在 `requests` 数组里，不是扁平 prompt；产物用 `get_asset_url` 换短链 |
| `connector__matrix__submit_video_generation` | 文生视频 / 首尾帧生视频，**MiniMax-H3 原生带音轨**（可含对白/环境音/音效），4–15s | 适合做「小栈的反应片段」；Hailuo-2.3 便宜但静音需再叠 TTS |
| `connector__matrix__synthesize_speech` | TTS | 设备端声音素材 |
| `connector__matrix__get_voice_list` | 音色列表 | 挑人格音色 |
| `connector__matrix__batch_text_to_audio` | 批量 TTS | — |
| `connector__matrix__audios_understand` / `videos_understand` | 音视频理解 | — |

> **对项目的意义**：`submit_video_generation` 的 H3 原生音轨能力，可以把「小栈的一个动作 + 一句话」做成一条带同步音频的短片 —— 这是**陪伴型产品的情绪载体**，比纯文字气泡强得多。值得进功能清单。

### 2.4 其他连接器（与设计无关但可用）

## 6. 设计软件选型建议（这是本节的核心结论）

| 路线 | 做法 | 成本 | 产出 | 风险 |
|---|---|---|---|---|
| **A. Penpot 画稿 → 人工复刻成代码** | Penpot 出 SVG/规格 → AI 按图写 SwiftUI/HTML | 低 | 静态稿 + 二次翻译 | **多一道人工搬运**，且"设计稿"与"实现"会漂移；Penpot 无 Apple 组件库，稿子不会天然像 iOS |
| **B. 直接写代码 + 截图迭代（推荐）** | 用 HTML/CSS 做视觉探索（浏览器秒级迭代 + 截图 + Playwright 回归）→ 定稿后转 SwiftUI | 低 | 截图即设计稿，**代码即设计稿** | 需要一套"代码 → 截图 → 评审"的流程（本项目已有 CDP 截图脚本，等于半成品） |
| **C. Figma** | 官方生态最全 | 订阅费 + 无 MCP | 静态稿 | 本机没有、连接器不支持、要装要付费 —— ⚠️ **2026-10-27 订正**：「连接器不支持」已失效（Figma Connector 已接入）；「本机没有（桌面版）」「要装要付费」仍成立，且社区套件需账号显式授权才可读。详见 `docs/research/89` |
| **D. 直接 SwiftUI + Xcode 预览** | 最正统 | 需要 Mac（本机无） | 真实稿 | Mac 问题未解决（见 `docs/research`） |

### 采用决策：**混合**
- **B 为主**：HTML/CSS 做视觉探索与评审原型（本项目已有 `ios/prototype/`，虽视觉被否，但**截图流水线可复用**）；SwiftUI 预览作为最终稿验证（等 Mac 到位）。
- **Penpot 作为可选补充**：只在需要画**非代码能表达的资产**（表情动作帧序列、图标精修、插画分镜）时用；不作为主界面设计载体。
- **Figma 不引入**（本机无、连接器无、且我们的交付物是可运行代码）—— ⚠️ **2026-10-27 订正**：本条决策**部分失效但结论维持**。「连接器无」已不成立（Figma Connector 已接入）；但「交付物是可运行代码」这条**理由仍然成立** ⇒ 「不把 Figma 当主稿载体」的决策**不变**，改为「**Figma 只做只读输入源**：读用户稿 → 核数值 → 生成/校验 SwiftUI」。详见 `docs/research/89`。
- **可复用/自造边界**：**视觉层全部自造**（这是"丑"的根），**校验层与资产层复用**（Playwright / axe-core / style-dictionary / Material Symbols / SF Symbols）。

## 7. 可复用方案（汇总）

```
可复用方案：
  - Penpot Desktop        用途：矢量草图 / 图标 / 表情帧    许可：MPL-2.0（自托管）  接入成本：低（已装）   替代自造的：界面草图工具
  - Playwright            用途：像素级视觉回归 + a11y 挂载  许可：Apache-2.0         接入成本：中（已装 py）  替代自造的：人工肉眼比对改版
  - axe-core / pa11y      用途：对比度 / tap target / a11y   许可：MPL-2.0 / LGPL-3.0 接入成本：极低          替代自造的：自写对比度脚本
  - stylelint + style-dictionary  用途：令牌唯一真源 + 外溢检测  许可：MIT / Apache-2.0  接入成本：低         替代自造的：:root 手写色值
  - chrome-devtools MCP   用途：交互态截图 / Lighthouse 审计    许可：内置             接入成本：零           替代自造的：自建截图脚本
  - Material Symbols / SF Symbols  用途：图标                   许可：Apache-2.0 / Apple  接入成本：低         替代自造的：自绘图标
  - matrix generate_image / submit_video_generation  用途：表情帧 / 插画 / 带音轨反应短片  许可：账号额度  接入成本：低  替代自造的：外购美术资产
  - computer-use          用途：驱动桌面设计软件 GUI          许可：内置               接入成本：中           替代自造的：无法脚本化的 GUI 操作
  - website_deploy        用途：原型公网发布 + 手机验收      许可：内置               接入成本：零           替代自造的：自建发布通道
采用决策：混合
理由：视觉层（画布、卡片、角色脸、动效节奏、层级）必须自造 —— 这正是此前"丑"的根因，套任何通用设计系统都会带回"通用感"；
      而校验层（对比度 / 令牌外溢 / 视觉回归）与资产层（图标 / 表情 / 图集 / 图标字体）复用现成工具，
      把"审美不可自动化"的部分留给人和设计令牌，把"有没有偷偷用错色值/对比度不达标"交给 CI。
```
