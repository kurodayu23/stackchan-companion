## 三、⭐ 本轮对「怎么做设计」的总体判断（收敛）

把 13 份文档 + 本轮 60+ 抖音视频放在一起看，**关于"怎么用 AI 做出好设计"，业界已经收敛到同一条路线**：

```
① 不要让 AI 猜审美      → 写死规范（PRODUCT.md / DESIGN.md / 设计宪法）
② 不要用形容词          → 用术语（"展开" 不是 "高级一点"）
③ 不要靠自觉            → 用确定性检测器（impeccable detect / nongeneric audit）
④ 不要一次性铺开        → 先功能后视觉；页面级先首屏再其余
⑤ 不要堆动画            → 动效是"点下去那一下"的反馈，不是装饰
```

⭐ 这 5 条**全部已经落在我们的体系里**（`19` 号 Floor 文档 = ①③⑤，`22` 号 = ②④，加上 `impeccable` 的 `detect` = ③ 的工具）。
**本轮没有推翻任何裁决，只是把"我们自己想到的"升级成"业界共识 + 有工具可查"。**
