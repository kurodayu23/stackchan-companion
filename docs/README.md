## 三条纪律

1. **`spec/` 是结论，`research/` 是过程。** 结论会被推翻，过程保留是为了能复核。
2. **规格书只规定"有什么"，不规定"长什么样"。** 视觉由下游独立产出，但不得违反 §4.6 的硬约束。
3. **没有证据的结论不写进 `spec/`。** 抓不到就写「未取得」，不填占位值。
