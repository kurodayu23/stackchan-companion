# 原型统一契约 · Prototype Contract v1.0

> **这份文件是所有原型方案的唯一共同输入。**
> 任何要做原型的人（AI 或人）先读这份，再动手。
> 目的：让 12–16 个方案**结构完全一致、视觉方向各不相同**，这样用户能在同一把尺子下比较，而不是被功能差异干扰。

---

## §0 一句话

**同一副骨架（12 个一级元素 + 4 个可交互状态），换 12–16 套 token（底色 / 强调色 / 圆角 / 字体 / 分隔 / 图形语言），得到 12–16 个可点击方案。**

> 用户原话：「必须要 app 有一个很强的能体现苹果的交付感，不是用什么样的颜色，而是有一种交付感，有那种质感」
> ⇒ **差别只在 token 层。结构、功能、交互、文案完全一致 —— 这样比较才成立。**

---

## §1 交付形态（硬性）

| 项 | 要求 |
|---|---|
| 文件 | `prototype/variants/<NN>-<slug>.html`，**单文件**，CSS 与 JS 内联 |
| 依赖 | **零外部依赖**。不引 CDN、不引字体文件、不引图片（图形用 CSS / inline SVG 画） |
| 尺寸 | 画板 **390 × 844**（iPhone 尺寸），居中，页面背景为展示用中性灰 |
| 演示容器 | 页面顶部一条**极简标题条**（方案名 + 一句话定位 + 序号），高度 ≤ 56px，不抢戏 |
| 交互 | **必须真的能点**。不是静态截图。见 §5 交互清单 |
| 尺寸自适应 | 窗口缩小时画板按比例缩放（`transform: scale()`），不能横向滚动 |
| 打开方式 | 直接双击用浏览器打开即可，无需服务器 |

### 1.1 画板内的结构（所有方案一致）

```
┌─────────────────────────┐  ← 390
│ ① 状态条（窄条）          │
├─────────────────────────┤
│                         │
│ ② 对话流（占主要面积）     │  ← 主角
│                         │
├─────────────────────────┤
│ ③ 输入框  ④ 麦克风        │
└─────────────────────────┘
   Tab: 陪伴 │ 小栈
```

- **陪伴页**（第 1 屏，默认显示）
- **小栈页**（第 2 屏，Tab 切换）：3D 姿态预览 + 姿态数值 + 三项读数 + 动作胶囊组
- **设置**（独立浮层，从状态条右上进入）：设置项分组，每组 ≤5 行，总深度 ≤2
- **Live Activity 紧凑态 / 展开态**（作为方案说明区展示，不是 Tab）

## §2 12 个一级元素（必须全部出现，缺一个 = 不合格）

> 出处：`docs/spec/01` §3。这 12 个是**全部表面加起来**的上限。

| # | 元素 | 在哪个表面 | 形态约束 |
|---|---|---|---|
| 1 | **小栈状态条** | 陪伴页顶 | 窄条（Live Activity 风格）；情绪图形 + 在场/等待 + 电量；**可滑动隐藏** |
| 2 | **对话流** | 陪伴页主体 | 消息列表；小栈的话 / 系统事件 / 你说的话 **三种来源视觉分层** |
| 3 | **输入框** | 陪伴页底 | 圆角输入；占位文案 ≤6 字 |
| 4 | **麦克风键** | 陪伴页底 | 圆形；按住说话 |
| 5 | **气泡旁动作键** | 陪伴页 | 轻触某条气泡后浮现；插入一个动作（点头 / 看别处 / 前倾） |
| 6 | **3D 姿态预览** | 小栈页 | 高 **160–200px**；用 CSS/SVG 画一个**抽象机器人头**（不引 three.js，不引 glb） |
| 7 | **姿态数值** | 小栈页 | 一行**等宽数字**：`左右 −12° · 俯仰 6°` |
| 8 | **三项状态读数** | 小栈页 | 一行：情绪 / 电量 / 在场 |
| 9 | **动作胶囊组** | 小栈页 | 横向**滑动**胶囊（8 个动作），**不是网格** |
| 10 | **Live Activity 紧凑态** | 灵动岛 | **只有图形，没有文字** |
| 11 | **Live Activity 展开态** | 锁屏 | 一行状态 + 一句话 + 一个动作按钮 |
| 12 | **通知（只有 4 类）** | 系统横幅 | 低电 / 久未互动 / 它想说话 / 设备异常 |

> ⚠️ **不许再加第 13 个一级元素。** 想加功能就折叠进二级（长按 / 滑动 / 展开）。

### 2.1 三种对话来源的视觉分层（必须能一眼分辨）

| 来源 | 形态 | 不得混用 |
|---|---|---|
| **小栈的话** | 无气泡底色的文本（或极浅底），左对齐 | 不能和系统事件同底色 |
| **系统事件** | 居中、小号、弱化、可带一条极细分隔线 | 不能带气泡 |
| **你说的话** | 有底色的气泡，右对齐 | 底色与前两者明显不同 |

## §3 Token 契约（**这是方案之间唯一允许不同的东西**）

在每份 HTML 的 `<style>` 顶部定义这一组 CSS 变量。**方案之间只改这一段。**

```css
:root{
  /* ── 画布与表面 ── */
  --bg:            #F2F2F7;   /* 页面画布 */
  --surface:       #FFFFFF;   /* 卡片 / 气泡底 */
  --surface-2:     #FFFFFF;   /* 次级表面 */
  --hairline:      rgba(60,60,67,.12); /* 分隔线 */

  /* ── 文字 ── */
  --text:          #000000;
  --text-2:        rgba(60,60,67,.62);
  --text-3:        rgba(60,60,67,.32);

  /* ── 强调（唯一） ── */
  --accent:        #FF6D60;
  --on-accent:     #FFFFFF;

  /* ── 语义 ── */
  --ok:            #28694B;
  --warn:          #805900;
  --danger:        #B62A43;

  /* ── 形状 ── */
  --r-xs: 4px;  --r-sm: 8px;  --r-ctl: 12px;
  --r-tile: 16px; --r-card: 20px; --r-sheet: 24px; --r-full: 999px;

  /* ── 间距（4pt 基准） ── */
  --sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px;
  --sp-5: 20px; --sp-6: 24px; --sp-8: 32px;

  /* ── 排版（只用系统栈，HIG Large 档） ── */
  --f-display: 34px; --f-title2: 22px; --f-title3: 20px;
  --f-head: 17px; --f-body: 17px; --f-callout: 16px;
  --f-sub: 15px; --f-foot: 13px; --f-cap1: 12px;
  --font: -apple-system, "SF Pro Text", "PingFang SC", "Helvetica Neue", sans-serif;
  --font-num: ui-monospace, "SF Mono", Menlo, monospace;

  /* ── 动效（**3 档时长 / 2 种曲线，全局唯一**） ── */
  --t-tap: 120ms;    /* T1 按压 / 微反馈 */
  --t-move: 280ms;   /* T2 页面转场 / 展开收起 */
  --t-story: 900ms;  /* T3 叙事（**全 App ≤3 处**） */
  --e-out: cubic-bezier(.16,1,.3,1);
  --e-std: cubic-bezier(.4,0,.2,1);

  /* ── 图形语言 ── */
  --face-ink:   #1C1C1E;  /* 设备小栈脸的墨色 */
  --face-blush: #FF6D60;  /* 腮红 / 情绪色 */
}
```

### 3.1 换方案时允许改的变量

| 变量组 | 允许范围 |
|---|---|
| `--bg / --surface / --surface-2 / --hairline` | 任意，但**必须**形成清晰的表面层级 |
| `--text / --text-2 / --text-3` | 任意，但**必须**满足对比度（正文 ≥4.5:1） |
| `--accent / --on-accent` | 任意**非紫非蓝渐变**方向；**单色**，不许渐变 |
| `--r-*` | 4/8/12/16/20/24/999 的组合，或整体调大一档（16/20/24/32） |
| `--font` | 系统栈 或 `"SF Pro Rounded"` 变体（只换标题/次标题） |
| `--face-ink / --face-blush` | 设备脸的墨色与腮红 |
| `--t-* / --e-*` | **只允许三档时长、两族曲线**；可调数值但不得增加档位 |

### 3.2 禁止改的（动了就不合格）

- 字号阶梯的**级数**：只用上表 9 级里的（34/22/20/17/16/15/13/12），不得自造中间值
- 一次交互的触感次数：**≤1**
- 玻璃：`backdrop-filter` 只允许出现在 **Tab 栏 / 顶部导航 / Sheet 浮层**，内容层禁止
- 设备脸尺寸：小栈脸在陪伴页占**视觉面积 ≥40%**

## §4 质感硬线（来自 `docs/spec/02`，命中即不合格）

| # | 规则 | 判据 |
|---|---|---|
| Q-1 | 动效只有一个家族 | 时长 3 档、曲线 2 种，**不允许页面自定义** |
| Q-2 | 高频交互不加自定义动效 | 按压/滑动/输入 ≤ 150ms，或用系统默认 |
| Q-3 | 反馈动效短而准 | ≤ 300ms，严格绑定动作 |
| Q-4 | 动效可被取消 | 播放中能立即执行下一步 |
| Q-5 | 持续振荡避开 ~0.2 Hz | 持续动画周期 **≥ 9000ms**；设备呼吸同理 |
| Q-6 | 字号只用系统 text style | 不得自造 pt |
| Q-7 | Tab ≤5 且永不溢出 | 本项目 **2 个 Tab**，禁 More |
| Q-8 | 分隔只用一种手法 | 描边 / 背景色差 / 阴影 **三选一** |
| Q-9 | 一次交互最多 1 次触感 | 不叠加；动效不能是唯一信息通道 |
| Q-10 | 无未接线元素 + 状态全覆盖 | **0 个死按钮**；六态各有设计 + 恢复动作 |
| Q-11 | 关键事件多模态 | 设备音效 ≤4 个；**日常安静** |

### 4.1 ⭐ AI 味反面清单 9 条（命中即不合格）

来源：`docs/spec/02` §4.4（原文取自本机 `design-system` skill）

| # | 禁止 |
|---|---|
| C1 | 奶油 / 沙 / 米色默认背景（可用，但**必须写明是刻意的**；若拿不准就别用） |
| C2 | 紫→蓝对角渐变当 hero；**任何强调色渐变** |
| C3 | bounce / elastic / overshoot 回弹；spring 过冲 |
| C4 | 卡片套卡片（嵌套 ≤1 层） |
| C5 | 染色背景上的低对比灰字 |
| C6 | emoji 当图标（全部用 inline SVG 或几何形） |
| C7 | 为每个功能新造一级入口 |
| C8 | 混用描边 + 阴影 + 背景色差三种分隔 |
| C9 | 流式文本每字触发整屏重排 |

### 4.2 状态六态（每个方案都必须画出来，至少能切换到）

`loading` / `empty` / `error` / `offline` / `permissionDenied` / `firstRun`

> 做法：在演示容器顶部放一个**极简**的"状态"切换条（不属于 App 本身，是演示脚手架），
> 点击切换 App 内的对应状态。**App 内部不许出现调试控件。**

## §5 ⭐ 交互清单（**必须真的能点**，不是静态图）

> 用户原话：「我要求是完全可以进行点击，跟到手机上面的原型差不多，点击交付都 OK 的」

| # | 交互 | 期望行为 |
|---|---|---|
| I-1 | **底部 Tab 切换** | 陪伴页 ⇄ 小栈页，切换有 T2 动效（不做花哨转场） |
| I-2 | **发送消息** | 点输入框旁的发送 → 消息气泡出现 → 小栈"正在想"状态 → 状态条变化 → 回复气泡出现（**流式逐字**，≤2s 内完成） |
| I-3 | **麦克风按下** | 按住出现波形/状态变化，松开恢复；**一次 interaction 只 1 次触感**（用视觉暗示即可，不强制真触感） |
| I-4 | **气泡动作键** | 点某条气泡 → 浮现动作键（点头 / 看别处 / 前倾）→ 选一个 → **小栈页的 3D 脸和姿态数值同步变化**（证明链路通） |
| I-5 | **3D 姿态拖拽** | 在小栈页拖动机器人头 → yaw ±128° / pitch 3~87° 范围内跟手 → 姿态数值实时变化 |
| I-6 | **动作胶囊组** | 横向滑动露出 8 个胶囊 → 点一个 → 3D 脸 + 姿态数值变化 |
| I-7 | **状态条下滑** | 状态条可滑动隐藏（露出更多对话） |
| I-8 | **设置浮层** | 顶部进入 → Sheet 下滑 → 分组项 ≤5 行 → 有一项能真的切换状态并**有反馈** |
| I-9 | **六态切换** | 演示脚手架切换 6 态，App 内容真实变化，**错误/离线/权限/首次四态必须有恢复按钮** |
| I-10 | **Live Activity 预览** | 展开态里能点动作按钮 → 有响应 |

> ⚠️ **验收红线**：所有可点元素 100% 有响应。**不允许出现点了没反应的按钮。**（Q-10）
> ⚠️ **JS 不许报错**。交付前用 `node --check` 或浏览器控制台确认无 error。

## §6 文案（**所有方案用同一套**，避免干扰比较）

**对话流示例（固定 7 条）**：

1. 系统事件 · 08:12 —— "小栈已连接"
2. 小栈 —— "你今天回来得比昨天早。"
3. 你 —— "在等我？"
4. 小栈 —— "等了 23 分钟。不算久。"
5. 系统事件 · 08:19 —— "小栈有点困了"
6. 小栈 —— "……我先眯一会儿。你叫我。"
7. 你 —— "叫你了。"

**状态条文案**：`小栈 · 有点困` + 电量图标
**小栈页三项读数**：`情绪 困` / `电量 82%` / `在场 是`
**动作胶囊 8 个**：`点头` `摇头` `看别处` `前倾` `后退` `抬下巴` `低头` `打招呼`
**设置分组**：
- 陪伴 · 小栈的名字 / 主动性 / 记住我的事
- 设备 · 舵机校准 / 亮度 / 声音
- 通用 · 通知 / 关于

> ⚠️ 中文文案**不许用 emoji**。语气按 ENFP 但克制，不撒娇过度。

## §8 方案命名规则

`prototype/variants/<NN>-<slug>.html`

- `NN` = 两位序号（01–16）
- `slug` = 英文短标识，≤3 词，用连字符
- 每份文件顶部必须写：**方案名**、**一句话定位**、**这条属于哪一类**（浅色原生 / 深色工具 / 暖色陪伴 / 单色克制 / 几何实验 …）
