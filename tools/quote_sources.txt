# ============================================================================
# 仓外引文登记表 —— `tools/check_quotes.py` 消费
# ============================================================================
#
# ⭐ 为什么需要这张表
#   `check_quotes.py` 判定「这条引文能不能在本仓里逐字回源」。
#   但有些引文**合法地**来自仓外：
#     · 官方 StackChan 固件仓库的 README（我们只读不 fork，不入库）
#     · Apple 官方文档的本机缓存（HIG / SF Symbols 等）
#     · 上游官方仓的源码注释
#   这些原文**不在本仓** ⇒ 机械比对必然「找不到」⇒ 会被误判成「抄错了」。
#   ⇒ 凡是这类引文，**必须在这里登记**（登记即审计：每条都要写明出处）。
#
# 格式（每行一条）
#   <出处标签> :: <归一化前的引文片段>
#
# 判定规则
#   * 归一化后（去 `**`、去反引号、折叠空白）**包含**登记的片段 ⇒ 算「可回源」
#   * 登记项要尽量**长且唯一**，避免误命中
#   * 登记前必须**核对过原文确实这么写**（不许凭印象登记）
# ============================================================================
